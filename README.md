# Realistic-tamagochi
A tamagochi but much more realistically accurate 
My parents have always been pretty negative about having a pet. To them i do not have the responsibility to keep one. Ive heard tamogochi before and tried to use it as a proof that i am a responsible person. But they still think its not releastic enough and till this day i dont have a pet. So this project is me tamogochi but much more accurate as having an actual pet. 

The tamagochi has the same playstyle as a normal tamagochi but i added a moisture and temperature sensor so that when you just threw somewhere like your bag it will die just like a real pet. I also made it so that you can make it stand on your table or any surfaces so that its easier to look at it. I also added a keychain hole for it so that its easier to bring around. 

I used a game character as a reference for building the case for the tamagochi because I would actually keep it as a pet. No kidding its cute af.
